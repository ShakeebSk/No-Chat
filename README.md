# 🚀 No-Chat

**No-Chat** is a fully-featured real-time messaging application supporting 200+ users with 1:1 chats, group conversations, voice/video calls, status updates, and rich media sharing.  
Built with Flutter & Firebase, it delivers WhatsApp-like experience across platforms.

---

# ⚙️ Core Components

| Component | Description |
|-----------|-------------|
| 🔐 **Auth System** | Firebase Authentication (Phone) |
| 💬 **Chat Engine** | Firestore real-time messaging |
| 📞 **Call System** | WebRTC voice/video calls |
| 📱 **Status** | 24-hour stories with images/videos |
| 🗂️ **Groups** | Create/manage group chats |
| 🔔 **Notifications** | Firebase Cloud Messaging |

---

# 🚀 Major Features

| Category | Features |
|----------|----------|
| 💬 **Messaging** | 1:1 chat, group chat, typing indicators, read receipts |
| 📱 **Calls** | 1:1 voice/video, group calls, mute/camera toggle |
| 📸 **Status** | Photo/video/text stories (24hr), view count |
| 🖼️ **Media** | Images, videos, documents, voice notes |
| 👥 **Groups** | Create groups, add/remove members, group admins |
| 🔔 **Presence** | Online/offline status, last seen |
| 📱 **Push** | Real-time notifications |
